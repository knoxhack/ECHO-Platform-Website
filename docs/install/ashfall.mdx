## What Ashfall Is

Ashfall is the first official ECHO survival experience. It is set after the Gridfall, in a world of toxic air, radiation pockets, orbital wreckage, broken relays, faction signals, and buried machine intelligence.

Ashfall is powered by ECHO systems rather than positioned as a standalone random pack. Terminal, HoloMap, Lens, Index, mission services, world services, and future PackOS validation all exist to make Ashfall feel like an official experience inside a larger platform.

## How to Play

1. Install ECHO Launcher.
2. Open the launcher and select Ashfall.
3. Install or update the Ashfall experience.
4. Let the launcher prepare the supported Minecraft/NeoForge-compatible profile.
5. Start through the launcher handoff.
6. Enter the Gridfall aftermath.

Use the launcher-managed install as the default path. It gives support and diagnostics a consistent starting point.

## What to Expect

Ashfall is built around hostile-world progression:

- Environmental survival through radiation, toxic exposure, filters, and storms.
- Terminal missions, faction intel, route objectives, and signal-driven progression.
- Lens scanner discovery for hazards, blocks, entities, machines, and hidden clues.
- HoloMap overlays for routes, crash sites, relays, anomalies, and world markers.
- Index discovery for recipes, items, archives, and progression knowledge.
- Late-game Nexus systems, signal storms, anomaly routes, and endgame consequences.

## Reporting Problems

When reporting an Ashfall issue, include the launcher version, Ashfall version or channel, platform, what you were doing, and whether repair was already attempted.

If the issue is install-related, start with [Troubleshooting](/docs/install/troubleshooting). If the issue happens during gameplay, include screenshots or logs when possible.
