# Creator Start Here

ECHO gives creators reusable modules, Pack Builder templates, datapack examples, config presets, theme templates, and validators.

Start with [Build Your First ECHO Pack](/docs/sdk/creator-guides/build-your-first-echo-pack), then choose modules, apply a template, add Index pages, add missions/tutorials/map markers, validate, and export.

Ashfall is not required. Use Ashfall only when building the official Ashfall profile or an explicitly Ashfall-derived pack.
