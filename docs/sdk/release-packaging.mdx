# Release Packaging

Runtime artifacts are owned by their release repos.

| Artifact | Owning repo |
| --- | --- |
| Launcher installers/update metadata | `knoxhack/ECHO-Launcher` |
| Module artifacts | `knoxhack/ECHO-Modules` |
| Native pack assets | `knoxhack/ECHO-Ashfall-Native-Edition` |
| NeoForge pack assets | `knoxhack/ECHO-Ashfall-NeoForge-Edition` |
| Standalone pack assets | `knoxhack/ECHO-Ashfall-Standalone-Edition` |
| SDK templates/schema bundles | `knoxhack/ECHO-SDK` |

Per-module outputs are documented in [Native SDK Artifacts](/docs/sdk/native-sdk-artifacts) and the module artifact contract in `ECHO-Modules`.
