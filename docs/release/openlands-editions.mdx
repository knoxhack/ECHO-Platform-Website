# Openlands Editions

Openlands ships through three thin edition repos that all consume the same `echoopenlandsprotocol` source data from `ECHO-Modules`.

## Editions

- Openlands Native Edition consumes `.echo-addon` artifacts for `ECHO-Native-Platform`.
- Openlands NeoForge Edition consumes `-neoforge.jar` artifacts for NeoForge compatibility.
- Openlands Standalone Edition consumes `-standalone.jar` artifacts for `ECHO-Standalone-Runtime`.

## Release Status

All Openlands edition entries are preview/planned until real artifacts, checksums, launcher install, update, repair, rollback, and parity validation exist.

## Contract

Echo IDs from `echoopenlandsprotocol` are the source of truth. Edition adapters may transform packaging and runtime wiring, but they may not rename gameplay content or replace original Openlands assets with copied Minecraft content.
