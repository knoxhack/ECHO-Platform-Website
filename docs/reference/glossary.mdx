## ECHO Platform

The operating platform for official ECHO experiences, modules, tools, launcher systems, PackOS validation, and future native runtime foundations.

## Ashfall

The first official ECHO survival experience. Ashfall proves the platform through real gameplay in a post-Gridfall world.

## ECHO Launcher

The official player gateway for installing, updating, repairing, validating, and launching ECHO experiences.

## PackOS

The validation and package layer for manifests, lockfiles, channels, snapshots, release gates, and future integrity checks.

## ECHO Modules

First-party building blocks that provide services, UI, world systems, progression, content, and platform integrations.

## AdapterCore

The shared gameplay contract between ECHO platform systems and runtime-specific hosts. AdapterCore calls enter `NativeLoaderRuntimeHost` first, `NeoForgeRuntimeHost` as compatibility fallback, and `StandaloneRuntimeHost` for parity/runtime harness work.

## Native Platform

The ECHO Native Loader lane. Native Loader is the primary future mod loader, with readiness claims tied to loaded module classes, registered AdapterCore services, and real runtime host mutation evidence.

## Terminal

The player command center for missions, routes, intel, rewards, inbox entries, and addon tabs.

## Lens

The scanner HUD for reading blocks, entities, fluids, machines, hazards, and progression clues.

## HoloMap

The spatial intelligence interface for routes, markers, hazards, relays, missions, bases, and anomalies.

## Index

The item, recipe, archive, usage, and discovery reference system.
